# ─────────────────────────────────────────────────────────────────────────────
#  CISO Toolbox — shared dependency constraints (DEP-06)
# ─────────────────────────────────────────────────────────────────────────────
#
#  Single source of truth for every version that is shared by more than one
#  module. Three generations of `requirements.txt` used to coexist across the
#  9 modules; waves 1 and 2 of the CVE remediation realigned them, and this
#  file is what keeps them aligned.
#
#  HOW IT IS ENFORCED
#  ------------------
#  This file is *not* referenced with `-c` from the module `requirements.txt`.
#  Each module's Docker build context is its own directory (`build: ./risk`,
#  …), so a parent-level file is unreachable from `COPY`/`pip install` inside
#  the image — `-c ../constraints.txt` would break every build. Changing the
#  build contexts to the repo root would mean touching docker-compose.yml and
#  sending the whole tree into every build context, which is worse.
#
#  Instead the alignment is checked statically:
#
#      bash tests/check-deps-drift.sh
#
#  which fails if any `requirements*.txt` (modules *and* add-ons) pins a
#  version that contradicts this file, or if a package shared by several
#  modules is missing here. It runs in CI (.github/workflows/dependency-scan.yml)
#  on every push and pull request.
#
#  WHEN YOU BUMP A VERSION
#  -----------------------
#  1. Update the pin here.
#  2. Update the same pin in every `requirements.txt` that carries it
#     (the drift check tells you exactly which files are out of line).
#  3. Re-run `bash tests/check-deps-drift.sh` and `osv-scanner --recursive .`.
#
#  This file is also usable directly as a pip constraints file for local work
#  outside Docker:  pip install -r risk/requirements.txt -c constraints.txt
#  (extras are intentionally omitted below — pip rejects extras in a
#  constraints file; the extras stay in the module requirements.)
#
#  Last realigned: 2026-07-28 (CVE remediation waves 1 + 2).
# ─────────────────────────────────────────────────────────────────────────────
